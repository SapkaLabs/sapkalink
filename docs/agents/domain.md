# Domain docs

This planning repository has one context. Read `GLOSSARY.md` when naming product concepts. Pairing, connection, camera session, and virtual webcam are distinct concepts; do not treat preview or an alternate phone app as evidence of the required interoperability.

Keep glossary entries limited to domain definitions. Record evidence-backed decisions in their Wayfinder tickets. Create ADRs only for consequential, hard-to-reverse choices with real trade-offs; no architecture ADR is settled during initial charting.
